# متصفح كويست الذكي — Quest AI Browser

متصفح ويب خفيف (≈160 KB) بلوحة ثنائية الأبعاد كبيرة لنظارات **Meta Quest 2 / 3 / 3S / Pro** (Horizon OS)، بواجهة عربية من اليمين لليسار وأزرار كبيرة.

**تحميل APK:** من صفحة [Releases](../../releases/latest).

## المزايا
- **صف محركات بحث (10)** في الأعلى: اسم المحرك وتحته حقل بحث خاص به، والصف يتحرك أفقيًا. البحث الآمن مُطفأ حيثما أمكن.
  - لمس حقل **فارغ** يفتح **تبويبًا جديدًا بنفس المحتوى** (وإن كنت في صفحة نتائج بحث، يُعاد نفس الاستعلام على المحرك الذي لمسته).
  - كتابة كلمة ثم Enter = بحث في **تبويب جديد**. زر «🔎 كل المحركات» يبحث في الجميع دفعة واحدة.
- تبويبات، رجوع/تقدم/تحديث، شريط عنوان، مفضلة، سجل، تنزيلات (يشمل blob/data)، بحث داخل الصفحة، وضع سطح المكتب/الجوال، فيديو بملء الشاشة، ومنح أذونات الكاميرا والميكروفون والموقع والملفات للمواقع.
- **ترجمة عربية** للصفحة داخل المتصفح (تلقائية اختياريًا)، وعبر وكيل Google Translate.
- **دبلجة وقراءة بصوت عالٍ**: أصوات TTS العربية المثبتة (الأنثوية أولًا) مع التحكم في السرعة وطبقة الصوت وخفض صوت الفيديو، وبديل أونلاين مجاني (Google TTS). الدبلجة الحية تترجم الترجمة المصاحبة (CC) للفيديو وتنطقها.
- **أدوات الصوت**: تضخيم حتى 300%، ومعادل بإعدادات جاهزة (صوت/باس/أفلام/حاد)، وتوحيد الصوت (Compressor + Limiter).
- **مشغل 360°/180°** (أحادي/SBS/TB) داخل الصفحة عبر WebGL، ومشغل أصلي لروابط الفيديو، وزر «افتح في Quest Browser» لمواقع WebXR.
- **خفة**: تفريغ التبويبات الخلفية من الذاكرة (افتراضيًا 3 تبويبات حية)، تسريع عتادي، تخزين مؤقت، بلا مكتبات خارجية.

## القيود (بصراحة)
- WebView في أندرويد **لا يدعم WebXR**، لذا تجارب VR الغامرة تُفتح في Quest Browser.
- Perplexity يتطلب تسجيل دخول مجاني. وقد تتجاوز إعدادات المنطقة أو الحساب معامل البحث الآمن.
- الترجمة والـ TTS الأونلاين تستخدم نقاط Google غير الرسمية المجانية وقد تتغير. أصوات Edge العصبية غير مضمنة.
- الدبلجة تتطلب وجود ترجمة مصاحبة (CC) للفيديو.
- مضخم Web Audio لا يعمل على وسائط عبر نطاقات أخرى بلا CORS أو محمية بـ DRM، والبديل هو LoudnessEnhancer العام (قد يرفضه النظام).

## التثبيت على Quest 2
فعّل **Developer Mode** من تطبيق Meta Horizon على الهاتف، ثم اختر طريقة:
1. **SideQuest** على الكمبيوتر: وصّل النظارة بكابل USB واسحب ملف APK إلى SideQuest.
2. **Bugjaeger** على هاتف أندرويد (مثل Redmi Note 14 Pro): وصّل الهاتف بالنظارة بكابل USB-C/OTG، واسمح بتصحيح USB داخل النظارة، ثم Packages → Install APK.
3. **من داخل النظارة**: افتح رابط APK في Quest Browser لتنزيله، ثم ثبّته من Files → Downloads (قد تحتاج تفعيل المصادر غير المعروفة). يظهر في المكتبة → Unknown Sources.

## English
Lightweight (~160 KB) Arabic RTL WebView browser for Meta Quest (Horizon OS 2D panel, 1280×800dp, resizable). It has a 10-engine search row, tabs, downloads, bookmarks, history, a desktop UA toggle, and fullscreen video. It also includes Arabic page translation, TTS read-aloud and live caption dubbing, an audio booster up to 300% with EQ, a 360/180 video viewer, and background-tab discarding.
Build: `./gradlew assembleRelease` (JDK 17, Android SDK 35). minSdk 29, targetSdk 34.
